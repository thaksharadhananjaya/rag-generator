❯ Build the Next.js(version:16.3.3) frontend for the RAG Generator based on the 
  Backend endpoints.                                                            
                                                                                
  Use Next.js with TypeScript, Tailwind CSS, React Query, React Hook Form, and  
  Zod.                                                                          
                                                                                
  The frontend should provide a clean, responsive user flow:                    
                                                                                
  Create Knowledge Base * Upload PDF * Monitor ingestion status * Ask questions 
  * Display grounded answer and sources.                                        
                                                                                
  Do not change the backend API contract.                                       
                                                                                
  IMPORTANT: Use ONLY the backend endpoints listed below. Do not invent,        
  rename, combine, or create additional backend endpoints.                      
                                                                                
  ## Backend API Endpoints                                                      
                                                                                
  ### Knowledge Base APIs                                                       
                                                                                
  Create a knowledge base:                                                      
                                                                                
  POST /api/v1/knowledge-bases                                                  
                                                                                
  Request body:                                                                 
                                                                                
  ```json                                                                       
  {                                                                             
    "name": "Company Handbook",                                                 
    "description": "Company policies and guidelines"                            
  }                                                                             
  ```                                                                           
                                                                                
  List knowledge bases:                                                         
                                                                                
  GET /api/v1/knowledge-bases                                                   
                                                                                
  Use the `pageable` query parameters:                                          
                                                                                
  ```text                                                                       
  ?page=0&size=20&sort=createdAt,desc                                           
  ```                                                                           
                                                                                
  Get a knowledge base:                                                         
                                                                                
  GET /api/v1/knowledge-bases/{id}                                              
                                                                                
  Delete a knowledge base:                                                      
                                                                                
  DELETE /api/v1/knowledge-bases/{id}                                           
                                                                                
  The delete operation returns HTTP 204 with no response body.                  
                                                                                
  ### Document APIs                                                             
                                                                                
  Upload a PDF document to a knowledge base:                                    
                                                                                
  POST /api/v1/knowledge-bases/{knowledgeBaseId}/documents                      
                                                                                
  Request content type:                                                         
                                                                                
  multipart/form-data                                                           
                                                                                
  Request field:                                                                
                                                                                
  ```text                                                                       
  file                                                                          
  ```                                                                           
                                                                                
  List documents belonging to a knowledge base:                                 
                                                                                
  GET /api/v1/knowledge-bases/{knowledgeBaseId}/documents                       
                                                                                
  Use the `pageable` query parameters:                                          
                                                                                
  ```text                                                                       
  ?page=0&size=20&sort=createdAt,desc                                           
  ```                                                                           
                                                                                
  Get a document:                                                               
                                                                                
  GET /api/v1/documents/{documentId}                                            
                                                                                
  Delete a document:                                                            
                                                                                
  DELETE /api/v1/documents/{documentId}                                         
                                                                                
  The delete operation returns HTTP 204 with no response body.                  
                                                                                
  Re-ingest a document:                                                         
                                                                                
  POST /api/v1/documents/{documentId}/ingest                                    
                                                                                
  This endpoint returns HTTP 202 Accepted and should be used for retrying       
  failed ingestion.                                                             
                                                                                
  ### RAG Query API                                                             
                                                                                
  Ask a question against a specific knowledge base:                             
                                                                                
  POST /api/v1/knowledge-bases/{knowledgeBaseId}/query                          
                                                                                
  Request body:                                                                 
                                                                                
  ```json                                                                       
  {                                                                             
    "question": "What is the annual leave policy?",                             
    "topK": 5,                                                                  
    "minScore": 0.7                                                             
  }                                                                             
  ```                                                                           
                                                                                
  `question` is required and has a maximum length of 4000 characters.           
                                                                                
  `topK` is optional and must be between 0 and 50.                              
                                                                                
  `minScore` is optional and must be between 0 and 1.                           
                                                                                
  Do not create a separate conversation/chat endpoint. All questions must use   
  the existing knowledge-base query endpoint.
